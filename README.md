# FORMA — site responsivo

Projeto front-end de página institucional inspirado na referência visual enviada.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador. Para uma experiência melhor, use a extensão Live Server do VS Code.

## Tecnologias
- HTML5 semântico
- CSS3 responsivo (Grid, Flexbox, clamp e media queries)
- JavaScript moderno
- GSAP + ScrollTrigger para animações de entrada e parallax
- Lucide para ícones
- Google Fonts: Manrope e DM Sans

## Observações
- As imagens são carregadas de URLs públicas do Unsplash e as fontes/bibliotecas usam CDNs; é necessária conexão com a internet.
- A marca e os textos foram recriados como uma interpretação original, não como cópia literal da Squarespace.
- O formulário de domínio é demonstrativo e não consulta disponibilidade real.
- Respeita `prefers-reduced-motion` e inclui menu mobile acessível com fechamento por link e tecla Escape.
